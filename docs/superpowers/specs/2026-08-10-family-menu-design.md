# 家庭菜单系统 MVP 设计规格

## 1. 目标与范围

构建一个供个人使用的响应式家庭菜单 Web 应用，帮助用户维护菜谱、规划一周三餐、复用历史菜单，并根据当前菜单生成采购清单。

第一版采用本地优先架构：无需注册、无需后端、无需联网即可使用。支持手机与电脑自适应布局，并提供 JSON 数据导入/导出作为备份。

暂不包含账号、云同步、家庭成员权限、营养分析、自动数量换算和外部网站菜谱导入。

## 2. 核心工作流

```text
菜谱库 -> 当前周菜单 -> 采购清单 -> 完成并归档 -> 历史菜单
                       ^                         |
                       +---- 自动规划/复制 ------+
```

首页是当前周菜单工作台。电脑端显示完整周表格，手机端按天切换。用户可以手动录入、从菜谱库选择、从历史菜单复制，或自动规划本周。

## 3. 页面与功能

### 当前周菜单

- 以周一至周日、早餐/午餐/晚餐组织菜单。
- 电脑端使用整周表格，支持点击餐格打开右侧编辑面板，并支持从菜谱库拖拽到餐格。
- 手机端按天切换，点击餐格打开底部编辑面板。
- 支持新增菜谱、清空餐格、替换菜品和生成采购清单。
- 自动规划生成可编辑草稿，不直接覆盖用户已确认的安排。

### 今日菜单

- 从当前周菜单派生显示当天三餐。
- 支持快速替换、查看食材和添加临时备注。

### 菜谱库

内置常见菜谱，用户可新增、编辑、删除和搜索。菜谱字段包括：菜名、分类、适用餐次、口味标签、烹饪耗时、难度、食材列表、做法和备注。

### 历史菜单

- 保留已归档的周菜单。
- 支持复制整周、某一天或某一餐到当前周。
- 复制后独立编辑，不修改历史记录。

### 采购清单

- 根据当前周菜单中的菜谱食材生成。
- 相同名称食材合并，保留来源菜谱。
- 数量由用户手动填写。
- 支持分类查看、手动新增、勾选已购买和清理已购买项。

## 4. 数据模型

- `Recipe`：菜谱及其分类、标签、食材和做法。
- `WeeklyMenu`：一周菜单，包含日期范围、状态和归档时间。
- `MealEntry`：菜单中的一个餐次安排，包含一个 `dishes` 数组；每项引用菜谱或保存临时菜名。
- `ShoppingList`：某周的采购清单及其项目状态。
- `AppSettings`：当前周、偏好设置和数据版本。

数据使用 IndexedDB 保存，结构化数据按对象仓库存储。导出文件包含版本号和完整数据快照；导入时先校验格式，失败不覆盖现有数据。

## 5. 自动规划规则

规划器按以下优先级筛选和排序：适用餐次 -> 最近 7 天避重 -> 同餐不重复 -> 同日主食/主要食材去重 -> 荤素汤主食分类平衡 -> 食材复用 -> 烹饪负担。默认早餐规划 2 道、午餐和晚餐各 3 道；菜谱不足时允许退化为可用组合，并提示重复原因。

规划器必须是确定性、可解释的本地规则，不调用外部 AI 服务。

## 6. 错误处理与恢复

- 删除菜谱和清空餐格需要确认；餐格删除提供撤销。
- IndexedDB 不可用时显示可理解的错误提示。
- 自动规划无可用菜谱时提示缺少的餐次或分类。
- 导入文件进行版本和字段校验，失败时保留原数据。
- 关键操作显示保存状态，避免用户误以为已保存。

## 7. MVP 验收标准

1. 可以创建、编辑、搜索和删除菜谱。
2. 可以一次性手动填写一周 21 个餐格，每个餐格可包含多道菜。
3. 可以从菜谱库、历史菜单复制或替换餐格内容。
4. 可以自动规划一周，并对近期重复做出合理规避。
5. 可以从当前周菜单生成采购清单并勾选项目。
6. 可以导出数据、清空后重新导入并恢复数据。
7. 手机和电脑视图均无明显溢出、遮挡或不可操作控件。

## 8. 后续可扩展项

账号与云同步、家庭成员协作、营养信息、份量换算、食材库存、外部菜谱导入和更高级的推荐模型均留待 MVP 验证后再决定。
