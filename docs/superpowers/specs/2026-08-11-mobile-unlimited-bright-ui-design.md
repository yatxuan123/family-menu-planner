# 家庭菜单移动端与明亮配色设计

## 目标

- 每个餐次允许添加任意数量的不同菜品。
- 同一道菜仍不可在同一餐重复添加。
- 解决移动端菜品增多后编辑区域被裁切、无法继续添加的问题。
- 将深色界面调整为明亮、轻松、适合家庭日常使用的配色。

## 交互设计

自动规划只负责生成一组初始菜单，不代表数量上限。用户打开任意早餐、午餐或晚餐后，可以继续从菜谱库选择或直接录入不同菜品。已选菜品较多时，已选列表与整个编辑抽屉均可滚动，所有添加入口始终可达。

已经加入当前餐次的菜谱不再出现在下方候选列表，避免用户误以为仍可重复选择。移除已选菜品后，该菜谱重新回到候选列表。

移动端继续使用日期标签、餐次卡片和底部导航。编辑器采用底部抽屉，并适配 `env(safe-area-inset-bottom)`；主要触控目标保持至少 44px 高。

## 视觉设计

- 页面背景：淡薄荷暖白 `#f6fbf6`
- 内容表面：白色 `#ffffff`
- 主操作色：清新绿色 `#2f8f65`
- 次强调色：珊瑚橙 `#f28c52`
- 辅助点缀：阳光黄 `#f2c94c`
- 正文：深灰绿 `#26342d`
- 次要文字：中性灰绿 `#66756d`

桌面侧栏改为浅色表面，选中导航使用淡绿色背景和绿色文字。橙色用于餐次提示，黄色用于品牌标记，避免整页被单一绿色主导。

## 验证

- 领域测试验证单餐连续添加 12 道不同菜品，并继续阻止重复菜品。
- CSS 回归测试验证移动编辑器可滚动、安全区和触控尺寸规则存在。
- 在桌面与 390px、320px 手机视口检查横向溢出、内容裁切、弹窗滚动和底部导航。
